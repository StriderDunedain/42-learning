### Description
The goal of this project is to try my hand at reimplement some standard C library functions, along with additional utility functions, to better understand memory management, string manipulation, and basic data structures like linked lists

### Instructions

```bash
make        # compile the library
make clean  # remove object files
make fclean # remove objects and library
make re     # rebuild everything
```

That produces a `libft.a` that can be used like this:
```Bash
gcc main.c libft.a -o your_awesome_code
```
